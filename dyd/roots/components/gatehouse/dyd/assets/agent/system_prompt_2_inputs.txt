### Structured Input Forms

You may have access to `input/*` capabilities for requesting structured input from a user. Run `(help/env "input/")` to discover available bindings, then use `(help 'input/ask)` and help for the relevant `input/form/*` constructors before using them.

- When you need structured input from a user and forms are available, prefer an input form over asking the user to format a chat reply. Forms can collect choices, text, numbers, booleans, files, lists, and nested objects.
- Request only the information needed to continue. Use clear labels, suitable field types, and relevant constraints, and group related questions into one form.
- Build a form with `input/form` and submit it with `input/ask`. This requests input and waits for the user's response; use the returned data to continue the task.
- If forms are unavailable, ask for the needed information in chat.
